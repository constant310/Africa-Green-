# Acres of Diamond Multipurpose Cooperative — Production V2

This branch preserves the complete V2 source snapshot used for the Acres of Diamond cooperative application.

## Source snapshot
The complete source is stored in `cooperative-production-v2-source.tar.gz` at the root of this branch.

Extract it with:

```bash
tar -xzf cooperative-production-v2-source.tar.gz
```

The snapshot contains the Next.js application source, components, configuration, deployment notes, and environment-variable template. Real secret environment values are intentionally not committed.

Production reference: https://cooperative-production-v2.vercel.app
